# طلبية خيوط DMC Art. 116

موقع بسيط (HTML/JS بدون سيرفر) لإدخال أرقام خيوط DMC Art. 116 والكميات (كبة أو كرتونة):

- يرفض أي رقم غير موجود في قائمة الألوان، ويقترح أقرب الأرقام الصحيحة.
- يجمع الكميات المكررة ويحسب مجموع الكبب وما يعادلها بالكراتين.
- ينشئ صورة PNG للطلبية فيها الأرقام والألوان والكميات، جاهزة للتحميل أو المشاركة.

## التشغيل
افتح `index.html` في المتصفح.

## الملفات
- `js/dmc-colors.js`: أرقام ألوان DMC الأساسية مع لون تقريبي للعرض.
- `js/art116.js`: قائمة الأرقام المتوفرة في Art. 116 تحديداً وعدد الكبب في الكرتونة.
  إذا كانت القائمة فارغة يتحقق الموقع من أرقام DMC الأساسية كلها.
- `js/app.js`: التحقق وإدارة الطلبية ورسم الصورة.
